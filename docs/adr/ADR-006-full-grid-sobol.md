# ADR-006: Full grid; Sobol sampling above 2000 combinations; no Bayesian search

- **Status:** Accepted
- **Date:** 2026-09-19

## Decision

گرید کامل؛ Sobol بالای ۲۰۰۰ ترکیب؛ بدون جستجوی بیزی

_English:_ Exhaustive grid search; uniform Sobol sampling above 2000 combinations; no Bayesian optimisation.

_Source: design document v1.0, §14 (decision log); rationale in §2._
