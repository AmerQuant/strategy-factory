# Feature list — Strategy Factory (v1.1)

Source of truth for acceptance criteria. Priority: MVP / P1 / P2. Task = Claude Code task id (design §13).


## ۰ زیرساخت

### F-0.1.1 — فرمت استاندارد و رابط آداپتور
- **Priority:** MVP · **Task:** T02 · **Module:** `data` · **Depends on:** —
- **Description:** تعریف اسکیما واحد: ts (شروع بار، UTC)، open/high/low/close/volume و ستون‌های اختیاری vwap، trades، spread؛ به‌همراه متادیتای سری: منبع، نماد منبع، نماد استاندارد، کلاس دارایی، تایم‌فریم، نوع قیمت، تعدیل، سشن، فید، منطقهٔ زمانی اصلی، تاریخ دانلود.
- **Acceptance:** هر آداپتور خروجی معتبر طبق اسکیما می‌دهد؛ اعتبارسنج اسکیما روی ستون یا متادیتای ناقص خطا می‌دهد؛ تست واحد برای هر فیلد.

### F-0.1.2 — آداپتور Alpaca
- **Priority:** MVP · **Task:** T04 · **Module:** `data` · **Depends on:** F-0.1.1
- **Description:** خواندن فایل‌های Alpaca (سهام آمریکا)، تبدیل به UTC، فیلتر سشن رسمی (RTH) با گزینهٔ نگه‌داشتن ETH، ثبت فید (IEX/SIP) و نوع تعدیل در متادیتا.
- **Acceptance:** روی نمونهٔ واقعی فایل‌ها بدون خطا اجرا می‌شود؛ بارهای خارج از سشن رسمی در حالت RTH حذف می‌شوند؛ فید و تعدیل در متادیتا ثبت است. (جزئیات فرمت پس از دریافت نمونه‌فایل)

### F-0.1.3 — آداپتور Dukascopy
- **Priority:** MVP · **Task:** T04 · **Module:** `data` · **Depends on:** F-0.1.1
- **Description:** خواندن CSV با تایم‌استمپ میلی‌ثانیه‌ای، اصلاح آفست UTC، تبدیل واحد حجم، ادغام سری bid و ask و ساخت mid و spread.
- **Acceptance:** سری bid و ask روی تایم‌استمپ یکسان هم‌تراز می‌شوند؛ spread = ask − bid همیشه نامنفی؛ آفست UTC هنگام دانلود از کانفیگ خوانده و اصلاح می‌شود.

### F-0.1.4 — آداپتور Yahoo

- **Acceptance:** دادهٔ روزانه با تاریخ درست و متادیتای تعدیل ثبت می‌شود؛ سری کمکی قابل استفاده در F-0.1.11 است.

### F-0.1.5 — آداپتور خروجی TradingView

- **Acceptance:** فهرست تریدها (زمان و قیمت ورود و خروج، جهت، سود) به ساختار استاندارد ترید تبدیل می‌شود.

### F-0.1.6 — بررسی کیفیت داده و گزارش

### F-0.1.7 — بازنمونه‌گیری و مرز روز
